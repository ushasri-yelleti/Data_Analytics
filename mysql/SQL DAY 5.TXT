Constraints:- rules that control the data entered into a table...
 

Why do we use constraints:-

1. maintain data integrity
prevent invalid data entry
avoid duplicate records
ensures relationship between tables,
make the database reliable and consistent.


integrity constraints

-----
1) NOT NULL:-

The not null constraints ensures that a column cannot contain Null(Empty) values. EVERY ROW MUST HAVE VALUE FOR THAT COLUMN.
not null:- doesn't allow null values.

2) unique:-

The unique key constraints ensures that all values in a column are different. duplicate values are not allowed 

3) primary key:-

Primary key is the combination of UNIQUE+NOT NULL


4) Composite key constraints:-

The composite constraints is known as If we applied more than one column as primary key then we should go for composite key constraints this contain is applicable only for table level not an at column-level.

5) Default key:-

The default constraint automatically assigns a predefined value if no value is provided during insertion


6) Check:-

The check constraints ensures that values satisfy a specified condition before insertion or update.


7) Foreign Key:-

The foreign key creates a relationship between two tables. it ensures that value in the child 6table must already exists in the parent table.



-----> Referential Actions:-

Referential actions define what happens to child table data when parent table data is updated or deleted.
