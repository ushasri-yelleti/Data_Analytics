Aggregate Functions()
============================
1.count() --> no. of records
2.min() --> minimum value
3.max() --> maximum value
4.avg(); --> average value
5.sum(); --> total value

Clauses
========
In MYSQL clauses are used to control how data is filtered, grouped, sorted or modified in SQL Queries.
They make SQL Statements more meaningful and powerful.

where clause
==============
Filter records based on specified conditions where clause can be used as comparison operators, logical
operators and...etc operators.

syntax
========
select column1,column2... from table where conditions;

Group By Clause
==================
the group by clause is used to group rows having the same values in one or more columns, it is commonly
used with aggregate functions such as min(),max(),sum(),count(),avg()

syntax
=======
select column-name,aggreage_function(column-name) from table-name group by column-name;

Having clause
==============
the having clause is used to filter grouped records after group by clause. it is similar to where but it
works on grouped instead of individual rows.

syntax
=======
select column-name,aggreage_function(column-name) from table-name group by column-name having condition;

Order By Clause
=================
the order by clause is used to sort the result set in ascending(ASC) or descending order.

syntax
=======
select column-name from table-name order by column-name;

DISPLAY DEPARTMENTS WHOSE AVERAGE MARKS ARE GREATER TAHN 75.
DISPLAY CITIES HAVING MORE THAN ONE STUDENT.

EXECUTION ORDER OF CLAUSES;
-------------------------------
FROM
WHERE
GROUP BY
HAVING
SELECT
ORDER BY

DISPLAY THE AVERAGE MARKS OF EACH DEPARTMENT  CONSIDERING ONLY STUDENTS OLDER THAN 20 YEARS. SHOW DEPARTMENT 
WHOSE AVERAGE MARKS ARE GREATER THAN 70 AND SORT THE RESULTS BY AVERAGE MARKS IN DESCENDING ORDER.

SYNTAX
==========
SELECT DEPARTMENT,AVG(MARKS)AS AVERAGE_MARKS FROM STUDENTS WHERE AGE>20
GROUP BY DEPARTMENT
HAVING AVERAGE_MARKS>70
ORDER BY AVERAGE_MARKS DESC;

2. DISPLAY THE TOTAL NUMBER OF STUDENTS IN EACH CITY CONSIDERING ONLY STUDENTS WHOSE MARKS ARE GREATER THAN 70. SHOW
CITIES HAVING MORE THAN ONE STUDENT AND SORT BY TOTAL STUDENTS.

SELECT CITY,COUNT(*)AS TOTAL_STUDENTS FROM STUDENTS WHERE MARKS>70
GROUP BY CITY
HAVING TOTAL_STUDENTS>1
ORDER BY TOTAL STUDENTS;
