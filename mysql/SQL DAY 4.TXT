--->TRUNCATE
--- Removes all records present in a table
SYNTAX:-
truncate table table-name;


---> drop deletes entire table structure and records whereas
---> truncate delete only records and doesn't affect the table structure




1. DROP
--- DEFINITION:- removes the table or object
1. table structure + data
2. table structure removed
3. performance is slow(due to full removal)

2. DELETE
DEFINITION:- removes specific rows from a table
1. specific rows(based on condition)
2. table structure intact
3. performance is slower (row-by-row)

3.TRUNCATE
DEFINITION:- removes all rows, keeps structure
1. all rows
2. table structure intact
3. performance is fast(bulk deletion)
